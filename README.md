# 狼人杀对局数据库 · 公开只读查询站

一个**纯静态、零依赖、只读**的狼人杀对局数据查询页。打开网页就能查，不需要服务器、不需要数据库、不需要登录。

- 🌐 在线查询：<https://wangzixiao-wzx.github.io/werewolf-db/>
- 📦 仓库：<https://github.com/wangzixiao-wzx/werewolf-db>

> **本仓库发布的是脱敏快照**：所有玩家昵称与别名（包括技能日志、备注里出现的名字）都已替换为「玩家01」「玩家02」…。板子、身份、阵营、胜负、座位、轮次、技能动作等统计数据**全部保留**，所以阵容分析、身份强度、板子冷宫榜等结论与原始数据完全一致。

## 能查什么

| 板块 | 内容 |
|---|---|
| 📊 概览 | 对局 / 玩家 / 板子 / 身份 / 座位 / 技能日志数量，阵营胜负分布，胜法分布，最近 8 局，数据完整度 |
| 📋 对局 | 按日期、板子、人数、胜方、胜法、参战玩家筛选；点开看 12 座身份、终阵营、存活与死因、完整技能日志、备注 |
| 👤 玩家 | 场次、胜场、胜率、拿狼率、常用身份、上次玩、距今；点开看该玩家每一局的座位与身份 |
| 🎴 板子 | 77 个板子的身份构成、开局数、上次开、冷宫天数；点开看板子规则与该板子所有对局 |
| 🎭 身份 | 126 个身份的阵营、使用次数、胜率；点开看出现在哪些对局 |
| 🔍 查询工具 | 玩家上次玩、板子冷宫榜（≥60 天标红）、随机抽板子 |
| 🧭 全局搜索 | 跨玩家 / 板子 / 身份 / 对局备注 / 技能日志检索 |

统计口径：胜率 = 本局 `winner_faction_id == COALESCE(final_faction_id, role.faction_id)`；别名合并到主名后统计。

## 它是什么、不是什么

```
werewolf.db  ──导出脚本──▶  data.js（脱敏快照）  ──▶  index.html（浏览器里纯 JS 计算渲染）
   本地维护      离线跑一次        静态文件                    无后端
```

- **是**：数据快照 + 纯前端页面。天然只读，无写接口、无服务端、无数据库。
- **不是**：实时数据库。本地数据更新后，需要重新导出并 push，线上才会刷新（约 1 分钟）。
- **不是**：原查询系统的移植版。原系统带录入、合并、导入、发牌等写功能，需要 Python 后端，无法跑在 GitHub Pages 上。

## 本地打开

双击 `index.html` 即可（`data.js` 放在同一目录）。或起个静态服务：

```bash
python -m http.server 8777
# 打开 http://127.0.0.1:8777/
```

## 数据更新

维护者在本地用 `export_static.py` 从 `werewolf.db` 重新生成脱敏快照：

```bash
python export_static.py --anonymize --db /path/to/werewolf-stats/werewolf.db
git add data.js && git commit -m "更新数据快照" && git push
```

脚本是只读的，不会修改数据库。`--anonymize` 会同时替换玩家主名、别名，以及技能日志和备注文本里出现的名字。

## 隐私说明

- 本仓库**不含**任何玩家真实昵称、别名、口令文件、数据库备份，也不含 `merge_log`、`name_pair` 等内部维护表。
- GitHub Pages 站点是公开的，因此这里只发布脱敏版本。
- 数据来自线下对局复盘，版权归所有参与者；如需删除某条记录，可提 issue 或联系维护者。

## 技术

单文件 `index.html`（CSS/JS 全内嵌）+ 一份 `data.js`（约 512 KB）+ 一个零第三方依赖的 Python 导出脚本。`export_static.py` 只用 Python 标准库；页面只用浏览器原生 API，不加载任何 CDN 资源。导出结果与直接查 SQLite 的统计口径已逐项对拍验证。
